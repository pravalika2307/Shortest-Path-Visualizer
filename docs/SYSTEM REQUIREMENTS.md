# System Requirements

## Hardware Requirements

| Component           | Minimum Requirement                   | Recommended Requirement           |
| ------------------- | ------------------------------------- | --------------------------------- |
| Processor           | Intel Core i3 (4th Gen) or Equivalent | Intel Core i5 (8th Gen) or Higher |
| RAM                 | 4 GB                                  | 8 GB                              |
| Storage             | 500 MB Free Disk Space                | 1 GB Free Disk Space              |
| Display Resolution  | 1366 × 768                            | 1920 × 1080 (Full HD)             |
| Internet Connection | Required for Deployment               | Stable Broadband Connection       |

## Software Requirements

| Software           | Version                                       |
| ------------------ | --------------------------------------------- |
| Operating System   | Windows 10/11, Ubuntu 20.04+, macOS Monterey+ |
| Python             | Python 3.10 or Above                          |
| Streamlit          | 1.45.0 or Above                               |
| Pandas             | 2.3.0 or Above                                |
| SQLite             | Built-in Python Library                       |
| Git                | Latest Stable Version                         |
| Visual Studio Code | Latest Stable Version                         |
